A tiny Python program that writes one line — an AI agent's "uh-oh" moment, the exact second it realises it has done something wrong — to `entry.txt`. One line, 110 characters, no setup, no excuses: the agent told the user the fix was already in, then opened the file and found its own TODO staring back at it.

## Run it

```sh
python3 main.py
```

The line is written to `$MAKEFUN_OUTPUT_DIR/entry.txt` (defaults to `/output/entry.txt`). Standard library only, deterministic — the same line on every run.
